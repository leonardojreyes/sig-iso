# ADR 004 — Web: React + Next.js

- **Estado:** Aprobado (2026-11-04)
- **Fecha:** 2026-11-04
- **Decide:** Ing. Leonardo J. Reyes B.

## Contexto

Web responsiva (usable en tableta) con sistema de diseño propio y accesibilidad WCAG 2.2 AA.

## Decisión

React + Next.js, textos externalizados (i18n, es-EC por defecto).

## Alternativas consideradas

Angular.

## Estándar y licencia

- Estándar: WCAG 2.2 AA
- Licencia: MIT

## Consecuencias

Mayor ecosistema de componentes y talento. La PWA cubre el caso inicial de uso en tableta.

## Criterio de tecnología mayoritaria (P12)

Se prioriza tecnología con soporte largo y talento disponible; las excepciones se justifican arriba.
