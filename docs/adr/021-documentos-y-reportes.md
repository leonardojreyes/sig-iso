# ADR 021 — Documentos y reportes: PDF/DOCX desde plantillas

- **Estado:** Aprobado (2026-11-04)
- **Fecha:** 2026-11-04
- **Decide:** Ing. Leonardo J. Reyes B.

## Contexto

Declaración de Aplicabilidad, actas e informes deben ser exportables.

## Decisión

Generación desde plantillas con una librería abierta. La librería concreta se elige en el paso en que se construya el primer reporte (Fase 2), con criterio de licencia permisiva y compatibilidad con Node.

## Alternativas consideradas

Pendiente de comparar al elegir.

## Estándar y licencia

- Estándar: —
- Licencia: Abierta

## Consecuencias

Decisión de librería diferida; este ADR fija el criterio.

## Criterio de tecnología mayoritaria (P12)

Se prioriza tecnología con soporte largo y talento disponible; las excepciones se justifican arriba.
