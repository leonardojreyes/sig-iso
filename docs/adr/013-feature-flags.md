# ADR 013 — Feature flags: OpenFeature + flagd

- **Estado:** Aprobado (2026-11-04)
- **Fecha:** 2026-11-04
- **Decide:** Ing. Leonardo J. Reyes B.

## Contexto

Activar módulos y normas por empresa y liberar de forma gradual.

## Decisión

OpenFeature como API y flagd como proveedor.

## Alternativas consideradas

Ninguna.

## Estándar y licencia

- Estándar: OpenFeature
- Licencia: Apache 2.0

## Consecuencias

Los módulos activos por empresa se apoyan en flags además de la configuración de empresa.

## Criterio de tecnología mayoritaria (P12)

Se prioriza tecnología con soporte largo y talento disponible; las excepciones se justifican arriba.
