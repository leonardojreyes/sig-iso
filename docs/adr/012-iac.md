# ADR 012 — IaC: OpenTofu + Helm + Argo CD

- **Estado:** Aprobado (2026-11-04)
- **Fecha:** 2026-11-04
- **Decide:** Ing. Leonardo J. Reyes B.

## Contexto

Todo como código y GitOps cuando haya clúster.

## Decisión

OpenTofu para infraestructura, Helm para la aplicación, Argo CD para entrega continua (manifiestos preparados en 0.8).

## Alternativas consideradas

Terraform (BSL, descartado por licencia).

## Estándar y licencia

- Estándar: HCL
- Licencia: MPL 2.0 / Apache 2.0

## Consecuencias

Con destino "solo local" se deja preparado y validado sin levantar clúster.

## Criterio de tecnología mayoritaria (P12)

Se prioriza tecnología con soporte largo y talento disponible; las excepciones se justifican arriba.
