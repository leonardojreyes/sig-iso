# libraries/normas — reglas

Librerías YAML validadas por esquema JSON (`packages/normas-schema`). Contienen solo: norma, edición, id de cláusula/control, título breve, guía propia redactada por SynapTech y mapeos. **Prohibido pegar texto de las normas.** Antes de importar una librería de terceros: verificar licencia y registrar ADR. Revisa con el subagente `revisor-cumplimiento`.
